## The line

> My fridge's ice maker drops one cube an hour, like it's rationing winter for a war it invented.

## Why this line

It roasts one specific, recognisable fridge quirk — an ice maker that technically works but dribbles out cubes at a glacial pace — instead of reaching for a generic insult. The laugh lands on a concrete detail anyone with a slow ice maker has lived through, and the twist pays off in the last few words: the fridge isn't broken, it's *rationing winter for a war it invented*, turning a lazy appliance into a paranoid little general stockpiling cold for a conflict only it can see. The line reads cleanly aloud as a single sentence, needs no setup, and the "war it invented" turn is a fresh image — no fridge-light gag, no expired-food joke, no diet punchline.

## Run it

```sh
node main.ts
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline, exactly one line, and a 1–200 character guard.
